# MailCraft 0.2.0-alpha.1

A pre-alpha desktop preview for Windows, macOS and Linux, with Apple styled, PC and Omarchy interfaces.

## In this update

- Refined unified inbox, right-hand reader, collapsible mailbox sidebar and pane dividers.
- Coordinated Settings, More menu, compose/reply and account setup designs, with signature selection and advanced tools retained.
- PC and Apple styled profile names; Omarchy/Tokyo Night styling and optional following of the active Omarchy palette.
- Improved Microsoft 365 setup, selected connected calendar/contact edits, attendee responses, single appointment creation/deletion and persistent review of pending changes.
- CalDAV endpoint discovery and calendar listing with transient credentials. Event sync and saved CalDAV accounts are not implemented yet.
- Updated documentation and screenshots using synthetic mailbox data.

## Downloads

- **Windows x86_64:** MSI installer or portable ZIP.
- **macOS:** universal DMG for Apple silicon and Intel.
- **Linux x86_64 and ARM64:** tar.gz, deb, rpm and AppImage.
- **SHA256SUMS:** checksums for the release downloads.

The Windows packages are unsigned. The macOS app is ad-hoc signed and not notarized. These builds can trigger operating-system prompts. This is an early preview, not a production-ready mail client.

Microsoft 365 and CalDAV work was validated with synthetic local fixtures, not live accounts. Saving an account or enabling sending does not verify server permissions. Recurring-series and full meeting lifecycle operations remain incomplete. Read the account and connected-organizer documentation before evaluating server-backed changes.
